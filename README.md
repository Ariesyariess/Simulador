# Proyecto VELOX — Simulador de Manejo

## 🚗 Descripción
Simulador educativo desarrollado con **Three.js** para la práctica de conducción segura y el cumplimiento de normas de tránsito.  
Incluye evaluación automática de infracciones, puntaje dinámico y entorno urbano 3D.
